# Kernel Track Documentation

This section explains the current Kernel Track for humans and agents. It is deliberately separate from the authoritative prompt source.

## Documents

- `architecture.md` - system boundaries and repository surfaces
- `component-index.md` - component-to-source/test/documentation map
- `governance.md` - change and review policy
- `versioning.md` - separation between historical MBP and Kernel Track versions

Documentation must remain traceable to authoritative files. If documentation and the kernel conflict, the kernel governs and the discrepancy is a tracked defect.
