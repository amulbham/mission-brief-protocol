## Reconciliations

### SYNTHESIZES inheritance

The RKI source registry omits `SYNTHESIZES`, but the active capsule schema already governs it as a DAG link. Silently removing it would invalidate sealed topology and violate RKI. Kernel 1.6 retains it as the ninth registered type and distinguishes explicit composite integration from non-composite convergence.

### Branch lifecycle

The source says BRANCHES_TO is discarded on close. Kernel 1.6 deactivates it for live inference while retaining its append-only audit record. Historical topology is not deleted.

### JIT boundary

RKI governs any compression or pruning from Kernel 1.6 onward. This release defines and tests preservation requirements but does not activate CAP-JIT-001 or the JIT feature flag.

## Authority impact

Constitutional LAW and enforcement-gate addition. VGATE-R gains no fact-verification, reasoning, topology-generation, or output-generation authority.
