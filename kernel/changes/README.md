# Kernel Changes

Every Kernel Track version change receives a numbered Markdown record.

A change record must include purpose, prior state, exact delta, reconciliations, affected files, test evidence, activation boundary, and release result.

The active Kernel 1.8 sequence is the Kernel 1.0 baseline followed by Changes 001 through 008. Kernel 1.9 candidate work continues through Change 012 and remains non-active until its release gate closes.
